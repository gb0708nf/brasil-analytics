    Sobre

    Brasil Analytics é uma plataforma desenvolvida por Gabriel Nunes Fernandes com o objetivo de democratizar o acesso a informações econômicas e promover a educação financeira por meio de dados, visualizações interativas e simulações.

    Tecnologias

    HTML5, CSS3, JavaScript Vanilla e Chart.js — sem frameworks pesados.

    Fontes de dados

    Banco Central do Brasil (SGS), IBGE (SIDRA) e Banco Mundial. Quando uma API está indisponível, a plataforma usa dados simulados temporários, sinalizados com a etiqueta simulado. Mapa, setores, governos e comparador internacional usam valores aproximados para fins educacionais.

    Aviso

    Projeto educacional e de portfólio. As projeções e simulações não constituem previsão oficial nem recomendação de investimento.
